# 📊 Customer Churn Analysis

An end-to-end **Customer Churn Analysis** project using **Python, SQL Server, and Power BI** to identify churn patterns, customer behavior, and key business metrics.

## 🛠️ Tools & Technologies

- Python (Pandas, NumPy)
- SQL Server
- Power BI
- Excel

## 🔄 Project Workflow

**Data Cleaning → EDA → Feature Engineering → SQL Analysis → Power BI Dashboard**

### 📌 Key Analysis

- Customer churn and retention
- Churn rate by contract & subscription type
- Churn by state and payment method
- Internet service analysis
- Customer tenure & churn
- Revenue and monthly charges
- Senior customer churn analysis
